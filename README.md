### ESCOPO
TEMA: Blog Culinário

O Blog culinário foi escolhido por ser um projeto mais simples de ser executado e com maior facilidade de organização e atração para uma proposta de site. O projeto é de um blog culinário com foco em mostrar de forma simples e didática como se executar uma receita, com um passo a passo, imagens e descrição, tendo como público-alvo adultos que não possuem dotes culinários e estão dispostos a aprender.

## Requisitos Funcionais:
RF01: O sistema deve exibir uma página inicial com destaque para o blog e suas principais receitas.
RF02: O sistema deve possuir um menu de navegação para acesso às páginas do site.
RF03: O sistema deve apresentar uma página contendo a lista de receitas disponíveis.
RF04: O sistema deve exibir imagens, títulos e descrições resumidas das receitas.
RF05: O sistema deve possuir uma página "Sobre" com informações do autor e do objetivo do blog.
RF06: O sistema deve apresentar um rodapé com informações de contato e links para redes sociais.

## Requisitos Não Funcionais:
RNF01: O sistema deve ser desenvolvido utilizando HTML5 e CSS3.
RNF02: O layout deve ser organizado, intuitivo e de fácil navegação.
RNF03: O site deve ser responsivo, adaptando-se a computadores, tablets e smartphones.
RNF04: As páginas devem carregar em tempo adequado para proporcionar uma boa experiência ao usuário.
RNF05: O código-fonte deve ser organizado, padronizado e de fácil manutenção.
RNF06: As imagens utilizadas devem possuir boa qualidade e ser otimizadas para não comprometer o desempenho do site.


### DOCUMENTAÇÃO

## Descrição do Projeto

Este projeto consiste no desenvolvimento de um blog culinário utilizando HTML5 e CSS3. O objetivo é disponibilizar receitas de forma organizada, oferecendo uma navegação simples, intuitiva e agradável para os usuários.
